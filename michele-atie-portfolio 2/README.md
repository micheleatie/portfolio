# Michèle Atié — portfolio

Portfolio personnel français / anglais, indépendant d’Habitat et Ambiances.
Présentation, recherche, blog, Digital Art et Design architectural en construction.

## Voir et modifier le site

Avec Node.js 22 ou plus : `npm run build`, puis `npm run check` et `npm run preview`.
Ouvrir ensuite http://127.0.0.1:4180/fr/index.html.

Les textes des articles sont dans `source/articles.mjs`, les autres textes dans
`scripts/build.mjs`, la présentation dans `source/style.css`.
Les images publiques optimisées sont dans `source/media` ; les originaux
conservés localement sont dans `source/assets`.

## Conserver le code en privé

1. Créer un dépôt séparé et sélectionner **Private** (nom libre).
2. Importer le contenu du dossier de code : `source`, `scripts`, `docs`,
   `package.json` et les fichiers de documentation à la racine du dépôt.
3. Valider avec **Commit changes**, puis vérifier la mention **Private**.
4. Ne pas activer GitHub Pages, Actions de déploiement ou autre hébergement.

L’archive `outputs/portfolio-code-prive.zip` contient le code complet à importer,
pas seulement les pages générées. Le dossier Adobe de sauvegarde reste séparé :
ne pas le charger dans ce dépôt. Les liens fonctionnent indépendamment du nom du dépôt.
L’aperçu est actuellement local ; le contact ouvre le logiciel de messagerie.
Il n’y a ni formulaire, ni collecte de données, ni suivi publicitaire sur ce portfolio.

Le site n’est pas publié. Un dépôt privé ne rend pas automatiquement un éventuel
site GitHub Pages privé : toute publication future demandera une décision distincte.
Les anciennes rubriques et les deux PDF ont été sauvegardés séparément ; leur
inventaire et leurs limites sont documentés dans `tasks.md` et le README de l’archive Adobe.
