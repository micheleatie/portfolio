# Portfolio Michèle Atié

## État et périmètre

Portfolio personnel bilingue FR/EN destiné à un dépôt GitHub Pages séparé.
Ne jamais modifier les dépôts Habitat et Ambiances ou Ambiance Index pour ce travail.
Contenus source : portfolio Adobe de l’utilisatrice, inventaire dans SOURCES.md.
Décision actuelle : code dans un dépôt GitHub privé ; aucune publication de site.
Le dépôt distant privé reste à créer/importer. Ne pas activer GitHub Pages ou
un déploiement public sans une nouvelle demande explicite.

## Commandes

- Génération : `npm run build` (Node 22+, aucune dépendance).
- Vérification : `npm run check`.
- Aperçu : `npm run preview`, port 4180.
- Stockage : importer le code complet à la racine d’un dépôt privé dédié ; Pages désactivé.

## Règles

- Toutes les pages, articles, menus et légendes existent en français et anglais.
- Liens relatifs : aucune hypothèse sur le nom du dépôt, aucun serveur requis.
- Pas de données privées, formulaire serveur, secret, traqueur ni dépendance Adobe en production.
- Préserver les œuvres et textes de l’utilisatrice ; ne pas inventer titres d’œuvres, diplômes ou dates.
- Design architectural : afficher « En construction » / « Under construction ».
- Présentation sobre : petit portrait, qualification « Architecte diplômée d’État »,
  ambiances au sens large et expérimentation sans focalisation immersive.
- Navigation visible sur mobile ; ne pas masquer les rubriques derrière un menu.
- Sur l’accueil, création d’outils pour les architectes, pas de texte de création numérique.
- Musique/animation, impression 3D, scénographie, architecture et interior design : en réserve, pas de rubriques publiques séparées.
- État actif et reprise : `tasks.md`. Scratch : `.codex-scratch.nosync/`.
